## 🚀 Projeto em Destaque

### ⛪ [Sistema de Gestão Paroquial (TCC)](https://github.com/alysson0321/paroquia-Santa-Teresinha)
> *Projeto de conclusão de curso com impacto real e implementação prática.*

Desenvolvi uma solução web completa para modernizar a gestão da **Paróquia Santa Teresinha** (Jucati-PE), substituindo processos manuais por um fluxo digital seguro.

* **O Desafio:** Digitalizar a gestão financeira (Dízimo), cadastros e agendamentos institucionais.
* **A Solução:** Painel administrativo robusto com autenticação e relatórios dinâmicos.
* **Tech Stack:** Node.js, Express, PostgreSQL e Front-end responsivo.

[🔗 Ver código e documentação](https://github.com/alysson0321/paroquia-Santa-Teresinha)
